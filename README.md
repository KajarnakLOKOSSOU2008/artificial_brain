# artificial_brain

> An intelligent system mimicking human brain functionalities.

An AI system inspired by the human brain — neural networks, decision-making and adaptive learning capabilities.

![artificial_brain](https://kajarnaklokossou2008.github.io/artificial_brain/)

## ✨ Features

- **Neural Network Architecture** — Modular, biologically-inspired network with cortical areas, feed-forward & recurrent pathways and sparse connectivity.
- **Adaptive Learning** — Online / continual learning via Hebbian + reinforcement signals — no full retraining required for new tasks.
- **Decision Making** — Hierarchical decision module with confidence-weighted outputs and exploration / exploitation balancing.
- **Pattern Recognition** — Classifies sequences, images and tabular patterns with attention-driven feature selection.
- **Memory System** — Short-term working memory + long-term episodic store with consolidation and forgetting curves.
- **Cognitive Simulation** — Run controlled experiments on perception, memory and decision cycles — export traces for analysis.

## 🏗 Architecture

The codebase is structured around small, swappable modules — every concern
(input, processing, output) lives behind a tiny interface so that
implementations can be replaced without touching call sites.
