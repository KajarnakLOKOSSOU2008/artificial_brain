Capabilities

Everything you need, batteries included

artificial_brain ships with a focused set of production-ready capabilities. No bloat — just the tools that make a real difference in day-to-day work.

🧬

Neural Network Architecture

Modular, biologically-inspired network with cortical areas, feed-forward & recurrent pathways and sparse connectivity.

🔄

Adaptive Learning

Online / continual learning via Hebbian + reinforcement signals — no full retraining required for new tasks.

🎯

Decision Making

Hierarchical decision module with confidence-weighted outputs and exploration / exploitation balancing.

👁

Pattern Recognition

Classifies sequences, images and tabular patterns with attention-driven feature selection.

💾

Memory System

Short-term working memory + long-term episodic store with consolidation and forgetting curves.

🔬

Cognitive Simulation

Run controlled experiments on perception, memory and decision cycles — export traces for analysis.

Architecture

Designed to be read, not just run

A clean separation between ingestion, transformation and output makes every stage testable, swappable and debuggable. Here is the canonical usage in code:

from artificial_brain import Brain, SensoryCortex, Hippocampus, PrefrontalCortex# brain = Brain( sensory = SensoryCortex(modality=['vision','text']), memory = Hippocampus(capacity=10_000), # episodic executive = PrefrontalCortex(decision='softmax'), ) brain.perceive(input_signal) # sensory encoding brain.learn(reward=0.87) # reinforcement + Hebbian action = brain.decide(context) # executive decision brain.consolidate() # short-term -> long-term
🧱

Modular by default

Every concern — input, processing, output — lives behind a small interface. Swap implementations without touching call sites.

🧪

Testable end-to-end

Stages are pure functions of their inputs. Unit and integration tests are first-class citizens of the repo.

📦

Deploy anywhere

Runs as a script, a CLI, a long-running service or inside a container. No vendor lock-in.
